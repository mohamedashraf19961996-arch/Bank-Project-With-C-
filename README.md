# Bank Management System

A console-based banking management system developed in C++ that simulates core banking operations such as client management, account transactions, user authentication, and financial services.

The project was designed to apply Object-Oriented Programming (OOP), file handling, modular programming, and real-world business logic implementation.

---

# Project Overview

The Bank Management System provides a practical simulation of banking operations through a menu-driven interface.

The application allows administrators and authorized users to manage customer accounts, perform financial transactions, and maintain banking records efficiently.

The project focuses on building clean business logic while following software engineering principles and object-oriented design practices.

---

# Features

## Client Management

* Add new clients
* Update client information
* Delete clients
* Search for clients
* Display all clients
* Store client records persistently

## Banking Operations

### Deposit

* Deposit funds into client accounts
* Validate transaction amounts
* Update account balances

### Withdraw

* Withdraw funds from accounts
* Prevent invalid withdrawals
* Validate available balance

### Transfer

* Transfer money between accounts
* Validate sender and receiver accounts
* Track transfer operations

### Balance Inquiry

* View client balances
* Display account details
